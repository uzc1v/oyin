# LEVELKIDS — Ta'limiy o'yin platformasi

Bolalar uchun zamonaviy, interaktiv ta'limiy o'yin platformasi (frontend demo).

## Ishga tushirish

Oddiy HTML/CSS/JS loyiha. Server kerak emas.

1. `index.html` faylini brauzerda oching.
2. Yoki lokal server:
   ```
   npx serve .
   ```
   yoki Python: `python -m http.server 8080`

## Xususiyatlar

- **3 til**: O'zbek, Rus, Ingliz (to'liq interfeys)
- **Ro'yxatdan o'tish / Kirish** (localStorage demo)
- **12 ta o'yin turi**: matematika, mantiq, xotira, so'z, ranglar, shakllar, sonlar, alifbo, hayvonlar, quiz, puzzle, rasm topish
- **Level va ball tizimi**, kunlik bonus
- **Do'kon**: 30+ avatar, 20 fon
- **LEVELKIDS World**: 5 dunyo (levelga qarab ochiladi)
- **Profil**, statistika, medallar
- **Ota-ona paneli** (demo)
- **Reyting jadvali** (lokal)
- **Responsive** dizayn (telefon, planshet, desktop)
- **Animatsiyalar** va silliq o'tishlar

## Texnologiyalar

- HTML5 + CSS3 + Vanilla JavaScript
- localStorage (ma'lumotlar saqlash)
- Google Fonts (Nunito)

## Eslatma

Bu **frontend demo**. Haqiqiy online akkauntlar, online musobaqalar, umumiy reyting va ota-ona nazorati uchun backend + ma'lumotlar bazasi kerak.

Bolalar ma'lumotlari faqat brauzerda saqlanadi.
